Node assignmentChoose which machine runs which node

Each rule sends one kind of node to one machine. Image input from also moves the nodes that make the image to that machine. Example: FaceDetailer runs on worker2, image input from worker1.

Every machine you pick runs the whole workflow, so one Run gives one image per machine. Use the settings to change a value on one machine, for example a different prompt or size on worker2.

In ComfyUI choose Workflow › Export (API), then paste the file here or load it. Every machine must have the models and custom nodes its nodes need. Only images travel between machines.
